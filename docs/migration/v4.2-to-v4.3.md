# Migration: v4.2 → v4.3

**TL;DR — DVAI-Bridge is now MIT-licensed, and the runtime license checker is gone.**

- Free for personal and commercial use. No license key, no JWT, no sign-up.
- Every SDK starts the same way in debug and release builds. There's no
  "production mode" check any more, so `LicenseRequiredError` /
  `LicenseRequiredException` can't be thrown.
- **This is a source-breaking change** if your code passes the old license
  options or reads `licenseStatus`. To fix it: **delete the argument, and
  delete `dvai-license.jwt` from your app bundle.**

Nothing else changes. The OpenAI HTTP surface, backends, offload, and
the SDK lifecycle all work as they did in v4.2.

## Removed API, per SDK

### TypeScript — `@dvai-bridge/core` (web, Node, React, vanilla)

| Removed | What to do |
| --- | --- |
| `DVAIConfig.licenseKeyPath` | Delete the option. |
| `DVAIConfig.licenseToken` | Delete the option. |
| `DVAI.licenseStatus` | Delete reads of it. The SDK no longer has a license state. |
| `LicenseValidator`, `LicenseRequiredError`, `DEFAULT_LICENSE_FILENAME` exports | Delete the imports and any `catch` branch for `LicenseRequiredError`. |
| `LicenseStatus`, `LicenseTier`, `LicenseValidatorOptions`, `LicenseDiscoveryOptions`, `DvaiLicensePayload` types | Delete the imports. |

Environment variables `DVAI_LICENSE_PATH`, `DVAI_LICENSE_TOKEN`,
`DVAI_FORCE_DEV`, and `DVAI_FORCE_PROD` are no longer read. Remove them
from your deploy config. Remove `dvai-license.jwt` from your project root /
`public/` folder.

## Also in this release

- **.NET iOS binding: no Mac Catalyst.** The `DVAIBridge.iOS` binding has
  shipped without a Mac Catalyst target since 4.2.1, because LiteRT-LM has
  no Catalyst slice. `net10.0-maccatalyst` apps can't consume it for now.
- **Docs moved** to <https://dvai-global.github.io/dvai-bridge/>.
- **msw 3 (web).** `@dvai-bridge/core` now depends on msw 3. Re-generate
  your service worker after upgrading: `npx dvai-bridge init` or
  `npx msw init <public-dir>`. The worker script must match the installed
  msw version.
